## About This Project

This repository contains a **UI prototype/demo** of a mobile application designed for a **Gait Analysis Wearable System**.

**Note:**

* This is **not the final product**
* No hardware integration is implemented yet
* It currently demonstrates only the **app interface and user flow**

---

## Purpose

The goal of this prototype is to showcase how the application will:

* Connect to a wearable device (future implementation)
* Manage users and sessions
* Display gait analysis data
* Handle cloud-based data storage

---

## Key UI Flows Demonstrated

* Device connection interface (Bluetooth + Hotspot flow)
* User selection and creation
* Session management screens
* Data visualization layouts
* Backup and data handling screens

---

## Future Scope

This app is intended to integrate with a wearable device that will:

* Track walking patterns using sensors
* Store data locally (SD card)
* Sync data with the app and cloud

---

## Note

This project currently focuses on **UI/UX demonstration only** and serves as a foundation for future IoT integration.
